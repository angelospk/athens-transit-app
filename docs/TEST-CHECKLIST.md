# Λίστα ελέγχου: όλη η εφαρμογή (2026-10-28)

Για δοκιμή στο κινητό. Σημάδεψε `[x]` ό,τι δουλεύει, και γράψε δίπλα ό,τι δεν δουλεύει.
Δοκίμασε με τοποθεσία ανοιχτή, σε μέρος με λεωφορεία κοντά.

Σημάδια: 🚌 χρειάζεται λεωφορείο στον δρόμο · 🕘 χρειάζεται συγκεκριμένη ώρα/μέρα ·
⏳ θέλει το deploy του backend `run-starts` (μέχρι τότε δεν εμφανίζεται).

## 1. Πρώτο άνοιγμα και ρυθμίσεις (≈5′)

- [ ] Onboarding: διαλέγεις στάση και γραμμές. Η πρώτη στάση γίνεται «Σπίτι».
- [ ] Ζητά άδειες ειδοποιήσεων και τοποθεσίας, και λέει γιατί.
- [ ] Περισσότερα › «Live κάρτα στις νέες ειδοποιήσεις»: αλλάζει.
- [ ] Περισσότερα › «Παρασκευή και Σάββατο βράδυ: το τελευταίο για το σπίτι»: αλλάζει.
- [ ] Περισσότερα › Widget «Η στάση μου»: μπαίνει στην αρχική οθόνη και δείχνει χρόνους.
- [ ] Περισσότερα › «Πώς διαβάζεται ο χάρτης» και «Στατιστικά δικτύου» ανοίγουν.

## 2. Χάρτης (≈10′)

- [ ] Σκούρος χάρτης. Τα λεωφορεία κινούνται ομαλά, χωρίς άλματα. 🚌
- [ ] Τα λεωφορεία που αργούν έχουν έντονο χρώμα καθυστέρησης. 🚌
- [ ] Κουμπί φίλτρου (εικονίδιο λεωφορείου) δίπλα στην αναζήτηση: αλλάζει τι δείχνει ο χάρτης.
- [ ] «Στρώματα χάρτη»: Λεωφορεία, Μετρό, Τραμ, Προαστιακός.
- [ ] Η κάτω κάρτα «Η στάση σου» / «Κοντά σου» είναι μικρή και δεν κρύβει τον χάρτη.
- [ ] Η μπάρα κάτω μικραίνει σε εικονίδια όταν κινείς τον χάρτη, και μεγαλώνει ξανά.
- [ ] Το πίσω του κινητού γυρνά βήμα-βήμα (στάση → λεωφορείο → γραμμή), όχι μόνο «κλείσιμο».

### Αναζήτηση
- [ ] Στάση, περιοχή, διεύθυνση, κατάστημα (π.χ. «syntagma», «Κηφισιά»).
- [ ] Τα chips Λεωφορεία / Μετρό / Τραμ / Προαστιακός φιλτράρουν τα αποτελέσματα.

### Στάση
- [ ] Αφίξεις live με λεπτά, καθυστέρηση, «N στάσεις πριν». 🚌
- [ ] «Περνούν επίσης»: οι άλλες γραμμές της στάσης.
- [ ] «Δεν ξεκίνησαν ακόμη · από το πρόγραμμα»: δρομολόγια μετά το τελευταίο live λεωφορείο.
- [ ] «Δεν ξεκίνησαν · δεν είδα λεωφορείο να φεύγει από την αφετηρία»: εμφανίζεται για ένα χαμένο δρομολόγιο. ⏳
- [ ] «Άλλη επιλογή» σε αυτό: ανοίγει τη Διαδρομή προς το τέρμα της γραμμής. ⏳
- [ ] Αποθήκευση στάσης (αστέρι) και αφαίρεση.

### Λεωφορείο
- [ ] Τρία πλακίδια (Τώρα / GPS / Όχημα) σε μία σειρά. 🚌
- [ ] «συνήθως N» → η ταχύτητα της γραμμής: σήμερα, ανά ώρα, τάση. 🚌
- [ ] «Επόμενες στάσεις» με λεπτά και ώρα («4′ · 08:12»). Οι περασμένες στάσεις δεν λένε «τώρα». 🚌
- [ ] «Κλείδωσε στο λεωφορείο»: ο χάρτης το ακολουθεί. 🚌
- [ ] Πάτημα στο σήμα της γραμμής (π.χ. «040») ανοίγει τη γραμμή. 🚌
- [ ] «Είμαι μέσα»: διαλέγεις στάση, ειδοποίηση μία στάση πριν. 🚌

### Γραμμή
- [ ] Τα λεωφορεία της γραμμής, τα κενά μεταξύ τους, «αργό σε N μ.». 🚌
- [ ] Καρτέλα προγράμματος: σημερινές αναχωρήσεις (πηγή OASA ημερήσιο).
- [ ] Κάθε δρομολόγιο σημειώνεται έγινε / χάθηκε, και το σύνολο «έγιναν N από M». ⏳

### Μετρό, τραμ, προαστιακός
- [ ] Σταθμός μετρό/τραμ: γραμμές, επόμενα τρένα με λεπτά και ώρα, στάσεις λεωφορείων κοντά.
- [ ] Σταθμός προαστιακού: live αναχωρήσεις και καθυστερήσεις.

## 3. Αγαπημένα (≈5′)

- [ ] Πρωί πρώτα η στάση «Σπίτι», απόγευμα πρώτα η «Δουλειά».
- [ ] Κάθε στάση: οι γραμμές σου με χρόνους. Χωρίς λεωφορείο: μία-δύο άλλες γραμμές με μικρά γράμματα.
- [ ] «Επιλογές» στάσης: Σπίτι / Δουλειά / τίποτα / αφαίρεση.
- [ ] «Γραμμές»: λεωφορεία στον δρόμο, πόσα αργούν· πάτημα → γραμμή στον χάρτη.
- [ ] Banner «Το τελευταίο … για το σπίτι» (Παρασκευή/Σάββατο 20:00–24:00, με στάση «Σπίτι»). 🕘
- [ ] «Ειδοποίησέ με 30′ πριν» στο banner → «Θα σε ειδοποιήσω», και η ειδοποίηση έρχεται. 🕘

## 4. Διαδρομή (≈15′)

- [ ] Από «Η θέση μου» → Προς μια περιοχή (π.χ. Κηφισιά): βγάζει αποτελέσματα.
- [ ] Τώρα / Αργότερα / «Με μετρό» αλλάζουν τα αποτελέσματα.
- [ ] Αντιστροφή από/προς.
- [ ] Κάρτα «Χωρίς αλλαγή»: το επόμενο λεωφορείο live, «φύγε σε N′». 🚌
- [ ] Κάρτα «Με μία αλλαγή» και κάρτα μετρό.
- [ ] Πάτημα σε κάρτα → οθόνη βήμα-βήμα: περπάτημα, λεωφορείο (στάση, πού κατεβαίνεις, πόσες στάσεις), αλλαγή, μετρό, περπάτημα, σύνολο και «φτάνεις ~HH:MM».
- [ ] Στη διαδρομή με μετρό λέει «ως τον σταθμό», όχι «ως τη στάση».
- [ ] Πάτημα σε βήμα → η στάση ή ο σταθμός στον χάρτη.
- [ ] «Πότε να φύγω» στο πρώτο λεωφορείο → «Φύγε σε N′» με το περπάτημα. 🚌
- [ ] «Ανέβηκα» → βρίσκει το λεωφορείο δίπλα σου και βάζει ειδοποίηση για τη στάση που κατεβαίνεις. 🚌

### «Ακολούθησέ με» (με κλειστή εφαρμογή)
- [ ] Πάτα «Ακολούθησέ με»: γράφει «Σε ακολουθώ…», ειδοποίηση «Σε ακολουθώ · γραμμή».
- [ ] Κλείσε την εφαρμογή, κλείδωσε την οθόνη, ανέβα στο λεωφορείο. 🚌
- [ ] Σε ~1–2′ μέσα στο λεωφορείο: «Είσαι στο …», «Θα σε ειδοποιήσω μία στάση πριν από …». 🚌
- [ ] Μία στάση πριν: η ειδοποίηση «κατέβα». 🚌
- [ ] Περπάτημα δίπλα στον δρόμο ή αναμονή στη στάση: ΔΕΝ λέει ότι ανέβηκες.
- [ ] «Σταμάτα»: σταματά η ειδοποίηση και η παρακολούθηση.

## 5. Ειδοποιήσεις (≈10′)

- [ ] Ειδοποίηση από στάση: λεπτά πριν / στάσεις πριν, και τι σημαίνει τώρα («όταν είναι στο …»). 🚌
- [ ] «Πες μου πότε να φύγω»: ζητά θέση, δείχνει περπάτημα και μπάρα.
- [ ] «Πες μου και αν αργεί»: μία ειδοποίηση όταν καθυστερεί 5′+. 🚌
- [ ] «Κάθε καθημερινή τέτοια ώρα;»: εβδομαδιαίος κανόνας στη λίστα Ειδοποιήσεις, ξεκινά μόνος την επόμενη μέρα. 🕘
- [ ] «Για το τελευταίο της ημέρας»: «Θα σε ειδοποιήσω 15′ πριν: το τελευταίο … περνά ~HH:MM».
- [ ] Live κάρτα στην οθόνη κλειδώματος με την πορεία· «Σταμάτα» από την κάρτα. 🚌
- [ ] Ειδοποίηση από λεωφορείο χωρίς ανοιχτή στάση (διαλέγεις στάση από τις επόμενες). 🚌
- [ ] Λίστα Ειδοποιήσεις: επεξεργασία, διαγραφή, «Συνέχισε» σε κανόνα που σταμάτησες από την κάρτα.
- [ ] Παρασκευή ή Σάββατο 21:00: «Βράδυ … · το τελευταίο για το σπίτι»· πάτημα → Αγαπημένα. 🕘

## 6. Στατιστικά (≈3′)

- [ ] Σήμερα και 28 ημέρες.
- [ ] Τάσεις: οι χειρότερες γραμμές σε 7/14/28 ημέρες.

## 7. Χωρίς δίκτυο (≈3′)

- [ ] Πτήση: η εφαρμογή λέει ότι είναι εκτός, δεν κολλά.
- [ ] Πίσω online: τα live γυρίζουν μόνα τους.
